**Pacotes Sazonais com Restrições**

Natal, Ano Novo, Feriados e Eventos

Se você deseja vender pacotes completos para períodos especiais, como **Natal, Ano Novo, feriados prolongados ou eventos**, é possível configurar pelo **Hunit**, utilizando **restrições de chegada, saída e estadia mínima**. Essas configurações garantem que os hóspedes reservem o pacote completo, evitando check-ins ou checkouts fora das datas desejadas.

**1.O que é pacote sazonal?**

Pacote sazonal é quando você vende um período COMPLETO para datas especiais.

**Exemplos:**

* Natal: 24 a 27 de dezembro (3 noites completas)
* Ano Novo: 28/12 a 02/01 (5 noites completas)
* Feriado prolongado: pacote de 4 dias
* Evento especial: show, festival (período completo)

**Por que usar pacote?**

* Hóspede NÃO pode chegar ou sair em qualquer dia
* Você vende o período COMPLETO
* Evita reservas de 1 ou 2 noites no meio do pacote
* Garante ocupação ideal em datas especiais

**Restrições Usadas**

|  |  |
| --- | --- |
| **Restrição** | **O que faz** |
| 1. Estadia Mínima | Define quantas noites no MÍNIMO (ex: 3 noites) |
| 2. Bloqueio Chegada | Impede check-in em certos dias (só pode entrar dia X) |
| 3. Bloqueio Saída | Impede checkout em certos dias (só pode sair dia Y) |

**Importante:**

* Faça cada restrição SEPARADA (uma de cada vez)
* EXCEÇÃO: Se bloqueio chegada e saída forem nas MESMAS DATAS EXATAS, pode fazer junto

### **2. Onde configurar o pacote?**

As configurações devem ser feitas **na tela de Atualizações**, onde você envia as restrições e valores para o sistema e canais.

Acesse:
 **Menu superior → Atualizações → Atualizações**

### **3.Selecione o período antes de aplicar as restrições**

Na **parte superior esquerda da tela**, selecione:

️ As **datas do pacote** (início e fim desejados para o pacote)

### **4.Ordem recomendada para configurar o pacote**

Para evitar falhas ou conflitos na atualização, **recomenda-se fazer em etapas**, nesta ordem:

* **Primeiro: Estadia mínima (Min Stay)**
   – Lançar apenas a regra de estadia mínima para exigir a quantidade mínima de noites do pacote.
* **Depois: Fechamento de chegada (Bloqueio de Check-in)**
   – Aplicar as datas em que o hóspede **não pode iniciar a reserva**.
* **Por último: Fechamento de saída (Bloqueio de Checkout)**
   – Aplicar as datas em que o hóspede **não pode finalizar a reserva**.

**Importante:**

* O ideal é **fazer cada restrição em lançamentos separados**, um por vez.
* **Somente quando os fechamentos de chegada e saída forem exatamente nas mesmas datas**, é possível atualizar os dois juntos no mesmo lançamento.

#### **5.Configurar Estadia mínima (Min Stay)**

* Define o número mínimo de noites que o hóspede deve ficar.
* Define o número MÍNIMO de noites que o hóspede precisa ficar.

**Exemplo prático:**

* Pacote Natal: Check-in 24/12 e Checkout 27/12 = 3 noites
* Você configura: Estadia mínima = 3 noites

![Imagem](https://raw.githubusercontent.com/hsystem1/converted-docs/main/batch_2026_07_10_165628_9c06/images/Como_criar_pacotes_s_image2_9c43b508.png)

#### **6. Configurar Fechamento de Chegada (Bloqueio de Check-in)**

* **O que faz:** Impede que o hóspede faça check-in em certos dias.

**Exemplo prático:**

* Pacote Ano Novo: Check-in SOMENTE dia 28/12
* Você BLOQUEIA chegada nos dias: 29, 30, 31/12 e 01/01. Assim, hóspede só pode entrar dia 28

![Imagem](https://raw.githubusercontent.com/hsystem1/converted-docs/main/batch_2026_07_10_165628_9c06/images/Como_criar_pacotes_s_image2_9c43b508.png)

#### **7. Configurar Fechamento de Saída (Bloqueio de Checkout)**

* **O que faz:** Impede que o hóspede faça checkout em certos dias.

**Exemplo prático:**

* Pacote Ano Novo: Checkout SOMENTE dia 02/01
* Você BLOQUEIA saída nos dias: 29, 30, 31/12 e 01/01. Assim, hóspede só pode sair dia 02

![Imagem](https://raw.githubusercontent.com/hsystem1/converted-docs/main/batch_2026_07_10_165628_9c06/images/Como_criar_pacotes_s_image2_9c43b508.png)

### **8. Exemplo prático – Pacote de Ano Novo (28/12 a 02/01)**

**Pacote**: 28/12 a 01/01 (5 noites)

|  |  |
| --- | --- |
| **Data** | **Configuração** |
| 28/12 | Check-in permitido / Estadia mínima = 5 noites |
| 29/12 | Bloquear chegada e saída (C / S) |
| 30/12 | Bloquear chegada e saída (C / S) |
| 31/12 | Bloquear chegada e saída (C / S) |
| 01/01 | Bloquear chegada e saída (C / S) |
| 02/01 | Saída permitida (Checkout) |

### **9. Selecione os canais que irão receber a atualização**

Após inserir as restrições:

* Vá até a **parte inferior da tela**
  ️Marque os **canais de vendas (Booking, Expedia, Airbnb, Decolar...)** que devem receber essa atualização

Clique em **Atualizar** para enviar os dados, no canto inferior direito.

![Imagem](https://raw.githubusercontent.com/hsystem1/converted-docs/main/batch_2026_07_10_165628_9c06/images/Como_criar_pacotes_s_image2_9c43b508.png)

Sem essa etapa, a configuração não será enviada para os canais.

### **10. Como verificar se está configurado corretamente?**

Após enviar a atualização, acesse a tela para confirmar se as informações estão sendo enviadas corretamente aos canais:

**Menu Calendários → Grade de informações**

Busque a **data do pacote** (canto superior direito)
 Selecione o **canal e a categoria**
 Clique para **carregar a grade**

**Verifique:**

|  |
| --- |
| Se os preços estão preenchidos |
| Se as restrições aplicadas (C / S / Estadia mínima) aparecem conforme configurado |
| Se não está mostrando stop de venda (preço em vermelho) ou valor “-” (sem tarifa configurada) |

**11. Também é possível acompanhar o envio**

**Acesse:**

**Menu superior → Atualizações → Relatório de atualizações**

📗 **Sucesso**: canal já recebeu a informação

🔄 **Em processamento**: aguarde o canal aceitar

❌ **Bloqueado**: será necessário acionar o suporte

Glossário

|  |  |
| --- | --- |
| **Termo** | **Significado** |
| Pacote Sazonal | Venda de período completo (Natal, Ano Novo, eventos) |
| Restrição | Regra que limita quando hóspede pode entrar/sair |
| Estadia Mínima (Min Stay) | Número mínimo de noites que precisa ficar |
| Bloqueio de Chegada (C) | Impede check-in em certo dia |
| Bloqueio de Saída (S) | Impede checkout em certo dia |
| Grade de Informações | Tela onde vê o que foi enviado aos canais |
| Lançamento | Cada vez que você configura e atualiza |
| Stop de Venda | Bloqueio total (preço vermelho, nada disponível) |
