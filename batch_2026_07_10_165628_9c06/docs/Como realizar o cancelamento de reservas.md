# **Como cancelar reservas**

O cancelamento de reservas deve ser feito **sempre pelo canal de origem**. Isso garante que as informações sejam processadas corretamente, evitando divergências de disponibilidade e possíveis overbookings.

## **1. Cancelamento pelo canal de origem**

O que são OTAS?

* OTAs são sites de reserva online como Booking.com, Expedia, Decolar, Hotels.com e outros.

Reservas criadas em OTAs (Booking, Expedia, Decolar, etc.) **só podem ser canceladas diretamente no canal onde foram feitas**.

**Importante:**
**Não é recomendado cancelar reservas de origem online (OTA) diretamente no PMS.**
 O PMS apenas atualiza disponibilidade — ele **não envia cancelamentos nem modificações** para o channel.

## **2. Cancelamento de reservas de operadoras, agências ou empresas**

Reservas provenientes de:

* Operadoras, Agências e Empresas (via **Hcorp** / **HoteisNet**)

Devem ser canceladas **diretamente com a operadora**.
A Hsystem **não possuem autonomia** para cancelar esse tipo de reserva.

## **3. Cancelamento de reservas pelo Hbook (motor de reservas)**

Quando a origem da reserva é o **Hbook**, o cancelamento pode ser feito diretamente pelo hotel.

### **Passo a passo para cancelar reserva no Hbook**

1. Acesse o Hbook:
    👉 <https://hbook.hsystem.com.br/Account/Login>
2. No menu principal, clique em **Reservas → Lista de reservas**.

![Imagem](https://raw.githubusercontent.com/hsystem1/converted-docs/main/batch_2026_07_10_165628_9c06/images/Como_realizar_o_canc_image2_8fa98f5b.png)

1. No campo **N° da reserva**, digite o número da reserva e clique em **Pesquisar**.

![Imagem](https://raw.githubusercontent.com/hsystem1/converted-docs/main/batch_2026_07_10_165628_9c06/images/Como_realizar_o_canc_image2_8fa98f5b.png)

1. Abra a reserva desejada.

![Imagem](https://raw.githubusercontent.com/hsystem1/converted-docs/main/batch_2026_07_10_165628_9c06/images/Como_realizar_o_canc_image2_8fa98f5b.png)

1. Clique no botão **“Cancelar reserva”**.

![Imagem](https://raw.githubusercontent.com/hsystem1/converted-docs/main/batch_2026_07_10_165628_9c06/images/Como_realizar_o_canc_image2_8fa98f5b.png)

**Glossário**

|  |  |
| --- | --- |
| **Termo** | **Significado** |
| Agência | Empresa que vende viagens e reservas de hotel para clientes. |
| Canal de Origem | Local ou plataforma onde a reserva foi criada originalmente. |
| Channel | Sistema que conecta o hotel a várias plataformas de venda ao mesmo tempo. |
| Hbook | Motor de reservas do hotel. Sistema para reservas diretas pelo site do hotel. |
| Hcorp / HoteisNet | Plataforma que conecta operadoras e agências aos hotéis. |
| Operadora | Empresa que vende viagens completas. Exemplos: CVC, Azul Viagens. |
| Overbooking | Quando o hotel vende mais quartos do que tem disponível. Problema grave! |
