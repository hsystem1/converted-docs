# **Chat Online no HAI (chatbot) — Como atender uma conversa e usar as ferramentas**

## **Contextualização**

Ao clicar em uma conversa na lista, o painel de atendimento é aberto à direita. Ele é dividido em três seções: cabeçalho (informações do cliente), histórico de mensagens e área de resposta com ferramentas.

### **Como acessar**

No HAI, acesse Menu superior → Chat Online → selecione uma conversa.

![Imagem](https://raw.githubusercontent.com/hsystem1/converted-docs/main/batch_2026_07_10_165204_05e9/images/Chat_Online_no_HAI_%28_image_29c4df7c.png)

## **Cabeçalho — Informações do cliente**

No topo do painel de atendimento:

* Ícone do canal de origem.

![Imagem](https://raw.githubusercontent.com/hsystem1/converted-docs/main/batch_2026_07_10_165204_05e9/images/Chat_Online_no_HAI_%28_image_29c4df7c.png)

* **Nome do contato.** "Visitante" indica cliente ainda não identificado. Clique no nome para editar o cadastro.

![Imagem](https://raw.githubusercontent.com/hsystem1/converted-docs/main/batch_2026_07_10_165204_05e9/images/Chat_Online_no_HAI_%28_image_29c4df7c.png)

### **Campos editáveis do cadastro**

* **Apelido:** nome da pessoa.
* **E-mail:** contato de e-mail.
* **Telefone:** telefone de contato.
* **Observações:** campo livre para notas sobre o cliente.

Após preencher, clique em Salvar Perfil.

### **Tags da conversa**

No cabeçalho, clique no botão + (ícone de tag) para adicionar etiquetas temáticas à conversa. Para criar uma nova tag:

* Clique em Nova tag;
* Defina o nome e escolha a cor;
* Clique em Salvar.

A tag ficará disponível como opção para todas as conversas e será exibida na lista central.

![Imagem](https://raw.githubusercontent.com/hsystem1/converted-docs/main/batch_2026_07_10_165204_05e9/images/Chat_Online_no_HAI_%28_image_29c4df7c.png)

## **Histórico de Mensagens**

A área central do painel exibe cronologicamente todas as interações e eventos da conversa. Além das mensagens, o histórico registra automaticamente eventos como:

* Quando um atendente assumiu a conversa (nome e horário);
* Quando o robô foi reativado;
* Quando a atribuição foi removida.

![Imagem](https://raw.githubusercontent.com/hsystem1/converted-docs/main/batch_2026_07_10_165204_05e9/images/Chat_Online_no_HAI_%28_image_29c4df7c.png)

O histórico garante rastreabilidade completa do atendimento — qualquer pessoa da equipe pode entender o que aconteceu na conversa sem precisar perguntar.

## **Área de Resposta — Ferramentas disponíveis**

**Quando o campo exibir a mensagem "Assumir atendimento":** o robô está ativo. Ao enviar qualquer mensagem, você assume automaticamente a conversa e o robô é desativado. O sistema exibirá um aviso confirmando a transição.

|  |  |
| --- | --- |
| **Ícone** | **O que faz** |
| Emoji | Adiciona emojis às mensagens para um atendimento mais humanizado. |
| Cifrão ($) | Abre a tela de envio de cotação. |
| Robô | Transfere a conversa de volta ao atendimento automático. |
| Prancheta (📋) | Abre o gerenciador de respostas rápidas. |
| Clipe de papel | Anexa arquivos — fotos, vídeos ou documentos. |
| Microfone | Grava e envia mensagem de áudio. |
| Seta para direita | Envia a mensagem digitada. |

![Imagem](https://raw.githubusercontent.com/hsystem1/converted-docs/main/batch_2026_07_10_165204_05e9/images/Chat_Online_no_HAI_%28_image_29c4df7c.png)

## **Como enviar uma cotação (ícone $)**

* Preencha: Data de check-in, Data de checkout, número de Adultos, Crianças e Código Promocional (opcional);
* Clique em Buscar — o sistema carregará os quartos e valores disponíveis para o período;
* Selecione (✔️) um ou mais quartos para incluir na cotação;
* Se desejar enviar apenas os preços sem link de reserva, marque a opção Ocultar botão reservar;
* Clique em Enviar cotação — o sistema gera e envia a proposta automaticamente na conversa.

![Imagem](https://raw.githubusercontent.com/hsystem1/converted-docs/main/batch_2026_07_10_165204_05e9/images/Chat_Online_no_HAI_%28_image_29c4df7c.png)

## **Como usar as respostas rápidas (ícone prancheta)**

Respostas rápidas são atalhos de texto para mensagens frequentes — ex.: endereço, horário de check-in, política de cancelamento.

### **Como usar durante o atendimento**

Digite / no campo de mensagem. O sistema exibirá automaticamente as respostas rápidas cadastradas para seleção.

### **Como criar uma resposta rápida**

* Clique no ícone de prancheta;
* Clique em + Adicionar;
* Preencha o Título (ex.: /Checkin) e a Mensagem completa (ex.: "O check-in inicia às 14h e o checkout até 12h.");
* Clique em ✅ para salvar.

![Imagem](https://raw.githubusercontent.com/hsystem1/converted-docs/main/batch_2026_07_10_165204_05e9/images/Chat_Online_no_HAI_%28_image_29c4df7c.png)

### **Ações disponíveis na lista de respostas**

* **Enviar (seta):** insere a resposta diretamente na conversa.
* **Editar:** altera o texto ou título.
* **Excluir:** remove do sistema.

## **Menu de ações (três pontinhos ⋮) no canto superior direito**

|  |  |
| --- | --- |
| **Opção** | **O que faz** |
| Perfil do cliente | Exibe e permite editar nome, e-mail, telefone e observações do contato. |
| Assumir atendimento / Reativar robô | Alterna entre atendimento humano e automático. Após assumir, a opção muda para Reativar robô — e vice-versa. |
| Marcar como não lida | Sinaliza a conversa como pendente de retorno na lista. |
| Atribuir a mim / Remover atribuição | Define ou libera a responsabilidade pela conversa. |
| Atribuir a outro usuário | Transfere o atendimento para outro colaborador da equipe. |
