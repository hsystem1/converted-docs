# **Como acionar o suporte para disponibilidade divergente no HUNIT**

Acione o suporte da Hsystem quando houver disponibilidade no HUNIT mas ela não estiver aparecendo no canal de venda — e você já tiver realizado todas as verificações de diagnóstico sem encontrar ou resolver o problema.

Antes de acionar o suporte, realize o diagnóstico completo descrito no artigo Como diagnosticar disponibilidade que aparece no HUNIT mas não no canal. As verificações resolvem a maioria dos casos sem necessidade de suporte.

## **Informações necessárias para o suporte**

Para que a equipe de suporte possa investigar com agilidade, reúna todas as informações abaixo antes de entrar em contato. Quanto mais completo o relato, mais rápida a resolução.

|  |  |
| --- | --- |
| **Informação** | **O que informar** |
| Canal | Qual canal não está exibindo a disponibilidade. Ex.: Booking.com, Expedia, Decolar, HBOOK, Airbnb. |
| Categoria | Qual tipo de quarto está com problema. Ex.: Standard, Deluxe, Executivo, Suíte Premium. |
| Período | As datas de check-in e checkout que você está tentando visualizar. Ex.: check-in 10/02/2025, checkout 12/02/2025. |
| Tipo de tarifa | Qual tarifa você está buscando, se aplicável. Ex.: Reembolsável, Não Reembolsável, Flex, Com café, Sem café. |
| Possui PMS? | Informe se utiliza PMS e qual é. Ex.: Desbravador, Newhotel, Hits, Hospedin. Se não possuir, informe que não tem. |
| Disponibilidade no PMS | A disponibilidade está correta no PMS? Responda: Sim / Não / Não se aplica. |
| Reenvio do PMS solicitado? | Já solicitou ao PMS o reenvio da disponibilidade para o HUNIT? Responda: Sim / Não / Não se aplica. |
| Grade de Informações vs Grade de Disponibilidade | Os valores de disponibilidade estão iguais nas duas grades? Responda: Sim / Não. |

## **Modelo de relato para o suporte**

**Canal com problema:** Booking.com **Categoria:** Standard 2 pax **Período:** check-in 10/03/2025, checkout 13/03/2025 **Tarifa:** Reembolsável **PMS:** Desbravador — disponibilidade está correta no PMS **Reenvio solicitado ao PMS:** Sim **Grade de Informações igual à Grade de Disponibilidade:** Não — a Grade de Disponibilidade mostra 5 quartos, mas a Grade de Informações mostra 0 para o Booking.com.

## **Notas**

* **Quanto mais detalhado o relato, mais rápida a investigação.** Informar apenas "o canal não está mostrando disponibilidade" sem os dados acima atrasa o diagnóstico.
* **Se o problema estiver em mais de um canal ou categoria,** informe todos no mesmo contato para que o suporte analise todos os casos em conjunto.
