# **Aba Geral das Configurações da Propriedade no HAI (chatbot)**

A aba Geral concentra as principais informações cadastrais e configurações básicas de funcionamento da propriedade dentro do sistema HBOT. É aqui que você define quem é a sua propriedade, como ela se comporta no atendimento e como o robô atua nas conversas com os clientes.

### **Como acessar**

No HAI, acesse Menu superior → Propriedade → Configuração → aba Geral.

![Imagem](https://raw.githubusercontent.com/hsystem1/converted-docs/main/batch_2026_07_10_165204_05e9/images/Aba_Geral_das_Config_image_7502e381.png)

Após qualquer alteração, clique em Salvar no canto inferior direito. Sem salvar, as mudanças não são aplicadas.

## **Dados cadastrais**

Os primeiros campos da tela identificam a propriedade no sistema:

|  |  |
| --- | --- |
| **Campo** | **O que representa** |
| Código do Cliente | Identificador único da propriedade no sistema Hsystem. |
| Nome | Nome comercial da propriedade. |
| CNPJ ou CPF | Documento fiscal da empresa — campo obrigatório. |
| Telefone | Número de contato principal da propriedade. |
| Tipo | Define se o cadastro é de uma propriedade individual ou de uma rede. |
| Tipo de Negócio | Segmento do estabelecimento — hotel, pousada, hotel fazenda, casa, etc. |

![Imagem](https://raw.githubusercontent.com/hsystem1/converted-docs/main/batch_2026_07_10_165204_05e9/images/Aba_Geral_das_Config_image_7502e381.png)

## **Configurações de funcionamento (toggles)**

Abaixo dos dados cadastrais estão as opções de personalização do comportamento da propriedade, cada uma ativada ou desativada por um toggle (botão de alternância):

|  |  |
| --- | --- |
| **Toggle** | **O que ativa** |
| A propriedade aceita crianças | Indica que o estabelecimento aceita hóspedes infantis. Pode influenciar regras e mensagens automáticas do chatbot. |
| Habilitar distribuição de atendentes | Permite que o sistema distribua os atendimentos entre diferentes operadores. Recomendado para equipes maiores. Esta opção também habilita a aba Distribuição de Atendentes no menu Propriedade. |
| Conta Facebook verificada | Ativa quando a página do Facebook da propriedade está verificada pelo Meta. |

![Imagem](https://raw.githubusercontent.com/hsystem1/converted-docs/main/batch_2026_07_10_165204_05e9/images/Aba_Geral_das_Config_image_7502e381.png)

A opção Habilitar distribuição de atendentes deve estar ativa para que a aba Distribuição de Atendentes apareça no sistema.

## **Configurações de controle do robô**

### **Reativar robô automaticamente após X minutos de inatividade**

Define o tempo que o sistema aguarda antes de reativar o robô automaticamente. Quando um atendente humano assume uma conversa e não responde dentro do tempo configurado, o robô é reativado e passa a responder o cliente automaticamente.

**Exemplo:** configurado para 10 minutos — se o atendente não responder em 10 minutos, o robô retoma o atendimento automaticamente.

### **Enviar mensagem de reativação do robô e conversa assumida**

Quando ativado, o HAI envia uma notificação automática ao cliente informando que o robô foi reativado ou que um atendente humano assumiu a conversa. Mantém o cliente informado sobre o status do atendimento.

![Imagem](https://raw.githubusercontent.com/hsystem1/converted-docs/main/batch_2026_07_10_165204_05e9/images/Aba_Geral_das_Config_image_7502e381.png)

## **Como salvar**

Após realizar qualquer alteração, clique no botão azul Salvar no canto inferior direito. Somente assim as mudanças são aplicadas com sucesso.
